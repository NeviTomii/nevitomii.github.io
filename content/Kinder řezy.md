| Ingredience      | množství |
| ---------------- | -------- |
| vejce            | 4x       |
| Cukr krupice     | 30g      |
| kakao            | 2 lžíce  |
| pol. mouka       | 100g     |
| olej             | 2 lžíce  |
| prášek do pečiva | 2 lžičky |
| tvaroh pol.      | 250g     |
| mascarpone       | 250g     |
| Med              | 3 lžíce  |
|                  |          |

- vejce a cukr vyšlehat do husté pěny
- předehřát troubu 170
- přidat kakao, pol. mouka, rostl olej, prášek o pečiva
- promíchat metlou
- trouba 170 stupnů 10 minut
- Tvaroh, mascarpone, med
- promíchat a hotovo
- hotové těsto zarovnat a rozdělit na třetiny
- jednu třetinu otočit a pomazat a přiklopit druhou třetinou

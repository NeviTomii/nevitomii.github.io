## Základy

***pokud napíšu kdekoliv / můžu vyhledat co chci bez psaní divných znaků***
také mohu text označit a použít zkratku z wordu

alt + x = # = heading = tag pokud bez mezery

**alt + (to vedle pravýho shiftu) = ** = bold (dvě hvězdičky zasebou)

[alt + F/G = [] = link](https://www.youtube.com/watch?v=dQw4w9WgXcQ) (pokud chci link uvnitř obsidianu udělam 2X [] [[Obsidian ovládání#Linky]])
~~~
[jménolinku](odkaz)
~~~

_shift + (to vedle shiftu) = _ = italics_

>alt + > = quote (musí být na začátku řádku)

~~~napis
alt + 1 = ~~~ = codeblock
~~~

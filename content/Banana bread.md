Dvě verze:

1. no effort peanut butter
2. medium effort regular ingredients

## Peanut butter version

https://youtu.be/EFibBc-pUtI?si=QLJRnIlGnscCwQ1i\&t=2150

| ingredience       | množství |
| ----------------- | -------- |
| banány            | 3        |
| peanut butter     | 125g     |
| vejce             | 2        |
| pečící prášek     | 5g       |
| vanilkový extrakt | 1tsp     |
| chocolate chip    | hodně    |
|                   |          |

- rozmačkám banány
- předehřát troubu na 175c
- přidám peanut butter a promíchám
- přidám vejce a promíchám
- přidám pečící prášek a vanilkový extrakt a promíchám
- přidám chocolate chips a promíchám, kus z nich si můžu nechat navrch
- do pekáče dát pečící papír, dovnitř dát těsto
- trouba na 175 na 25 minut

## Regular version

https://www.youtube.com/watch?v=bScZ01UaYEM

| ingredience       | množství |
| ----------------- | -------- |
| banány            | 2        |
| máso              | 115g     |
| cukr              | 200g     |
| vejce             | 2ks      |
| vanilkový extrakt | 1tsp     |
| poloh mouka       | 240g     |
| pečící prášek     | 5g       |
| zakysaná smetana  | 115g     |
| chocolate chips   | hodně    |

- rozmačkám banány
- přidám máslo 115g v hrnečku rozpustit
- do másla přidat 200g cukru
- přidat 2 vejce
- předehřát troubu 165
- přidat vanilkový extrakt 1tsp, pak pořádně promíchat
- dpřidat polohrubou mouku 240g, pečící prášek 5g, čtvrtinu čajové lžičky soli
- tekuté přidat do pevného
- přidat zakysanou smetanu
- přidat chocolate chips
- dát do pekáče a do trouby na 165c na 70 minut

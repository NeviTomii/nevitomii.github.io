| ingredience       | množství            |
| ----------------- | ------------------- |
| borůvky           | 250g                |
| hnědý cukr        | 1tbsp               |
| citronová kůra    | 1/2lemon            |
| polohrubá mouka   | 125g                |
| kypřící prášek    | polovina sáčku (5g) |
| cukr krupice      | 35g                 |
| mléko             | 120ml               |
| vanilkový extrakt | 1tsp                |
| máslo             | 30g                 |
|                   |                     |

- smíchat mouku, cukr, kypřící prášek
- přidat rozpuštěné máslo (stačí v hrníčku v mikrovlnce)
- předehřát troubu na 180c nefoukací
- mléko
- vanilkový extrakt
- borůvky (pár nechat navrch)
- promíchat
- přendat do pekáče s pečícím papírem
- borůvky navrch
- hnědý cukr a citronová kůra navrch
- do trouby 180c na 35 minut

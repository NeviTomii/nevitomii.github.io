| Ingredience      | množství |
| ---------------- | -------- |
| párek            | 1 bal    |
| cibule           | 1-2x     |
| česnek           | ano      |
| těstoviny        | 250g     |
| hovězí vývar     | 710ml    |
| rajčatová omáčka | 250ml    |
| sýr              | 100g     |
| mléko            | 80ml     |
|                  |          |

- nakrájet cibuli dát na pánev
- nakrájet párek dát na pánev
- protlačit česnek
- přidat těstoviny
- přidat hovězí vývar
- přidat rajčatovou omáčku
- přisypat - pepř, paprika, oregano, cibule powder
- promíchat, počkat než začne bublat, ztlumit teplo a přiklopit pokličkou na 15 minut
- zkontrolovat že jsou těstoviny uvařené
- přidat sýr a trochu mléka

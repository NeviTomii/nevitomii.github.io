když kliknu pravym na nějakej note, můžu splitnout zobrazení mezi 2 nebo více notes

vykřičník před odkaz rendrne odkaz (obrázek) rovnou
# Vyhledávání

ctrl + shift + f pro vyhledávání

ctrl + O = quickswitcher pro otevření note podle jmena

když kliknu na tři tečky pod searchbarem můžu si bookmarknout search

# Properties

každý note může mít properties, property přidám pomocí ctrl + ;
pokud si vzpomenu přidat properties předtim než jsem cokoliv napsal, stačí napsat "---"

když chci přidat novou property tak místo vybrání napíšu nové jméno, když kliknu na obrázek vpravo můžu vybrat typ.

uvnitř property může být [[Obsidian ovládání#Linky|link]]


# Tagy

když dělám tag, můžu udělat i podtag, apak vyhledat pouze podtag

"#"tag/podtag

tagy mohou být buď volně v textu, nebo v properties daného notu
-> dám ctrl + p a napíšu property

# Linky

~~~
[[wikilinks]]
[[wikilinks|alias]]
[[wikiling#link to heading]]
~~~

link může být součástí property -> když např. chci odkázat na příští note stejného typu můžu si vytvořit property next a uvnitř ní zadat link

pro synchronizaci git repa s quartzem používám obsidian plugin quartz syncer

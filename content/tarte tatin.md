možná to nezkaramelizovalo protože byl moc velkej hrnec
zkusit ještě jednou s mín cukrem a dělat dýl, pokud nevyjde můžu místo pink lady zkusit granny smith jablka, můžu změnit teplotu v troubě a můžu listové těsto na chvíli odendat

| ingredience                     | Množství |
| ------------------------------- | -------- |
| jablko pink lady                | 6ks      |
| listové těsto (idealně máslové) | 1ks      |
| cukr krupice                    | 100g     |
| máslo                           | 100g     |
# Postup

(ctrl + u to uncheck all)

- [x] vezmu pánvohrnec 18cm průměr
- [x] jablka oškrábu škrabkou, rozdělim na čtvrtiny, z každé čtvrtky vyndám středovou část
- [x] JABLKA NECHÁM PŘES NOC VYSCHNOUT
- [x] předehřeju troubu na 160stupňů foukací mod
- [x] strany hrnce do trouby potřu máslem
- [x] na dno hrnce vyskládám 100g másla
- [x] na dno hrnce vysypu 100g cukr krupice
- [x] vyskládám jablka na stojato podel hrnce, tak aby byly namačkaný na sebe
- [x] z listového těsta udělám kruh který je o 5 cm větší než hrnec
- [x] listové těsto dám navrch jablek, umačkám aby přilehlo k rohům, zbytek převalím na sebe aby se nelepilo na stěnu
- [x] do těsta udělam nožem pár dírek
- [ ] podle receptu se bude dělat 3 hodiny, zkontrolovat po třech apak bude potřeba dalších 30 až 60 minut
- [ ] zbytek listového těsta můžu použít na [[pizza šnek]]
